## 💼 Business Model

### Revenue Model

**Project-Based Consulting (60%)**
- Fixed-scope infrastructure/platform engineering projects
- Typical engagement: R500k - R2.5M per project
- 3-6 month project duration
- Examples:
  - "Migrate AVD infrastructure to Entra ID hybrid model"
  - "Implement IaC for cloud infrastructure"
  - "Design and deploy MLOps platform"

**Retainer Services (40%)**
- Ongoing strategic guidance and support
- Monthly retainer: R25k - R200k per client
- 10-20 hours per month commitment
- Examples:
  - "CTO advisory services - 2 days per week"
  - "Infrastructure optimization retainer"
  - "Platform engineering mentorship"

**Blended Model**
- Project + retainer combination
- Initial project to establish relationship
- Transition to ongoing retainer for maintenance/optimization

### Pricing Strategy

**Value-Based Pricing**
- Price based on client value and outcomes
- Not commoditised hourly billing
- ZAR pricing (no forex volatility)
- Transparent, fixed pricing for projects

**Tiered Service Levels**
- Standard package
- Premium with additional support/responsiveness
- Enterprise with dedicated capacity

## 🎯 Strategic Focus

### Three Core Service Areas

1. **Platform Engineering** (40% of business)
   - Infrastructure as Code transformation
   - DevOps and CI/CD implementation
   - Cloud-native architecture
   - Automation and scripting
   - **Positioning:** Help enterprises modernize infrastructure through code and automation

2. **Azure Modern Workplace** (35% of business)
   - AVD (Azure Virtual Desktop) design and optimization
   - Entra ID (formerly Azure AD) identity governance
   - Intune device management
   - Microsoft 365 deployments
   - **Positioning:** Specialists in Azure's Modern Workplace stack

3. **AI Infrastructure & MLOps** (25% of business)
   - MLOps platform architecture
   - AI/ML pipeline design
   - Model deployment and monitoring
   - Enterprise AI governance
   - **Positioning:** Help enterprises build AI capabilities responsibly
